<h1 align="center">
  Ali Hassan — Portfolio
</h1>
<p align="center">
  Personal portfolio of Ali Hassan, game developer. Built with Vite and React 19, using Material UI and Bootstrap 5.
</p>

## 🛠 set-up

1. Install the dependencies

   ```sh
   npm install
   ```

2. Start the development server

   ```sh
   npm run dev
   ```

## 🚀 build for production

```sh
npm run build
```

## 🧩 where the content lives

| Section | File |
| ------- | ---- |
| Hero / intro | `src/components/Intro.jsx` |
| About + tech stack | `src/components/About.jsx` |
| Experience tabs | `src/components/JobList.jsx` |
| Games | `src/components/Games.jsx` |
| Software projects | `src/components/Projects.jsx` |
| Nav + social links | `src/components/NavBar.jsx`, `src/components/SidebarNav.jsx` |
| Footer | `src/components/Credits.jsx` |

The ASCII portrait on the hero is generated from `public/profile.png`. After replacing that
image, regenerate the pre-baked particle data:

```sh
node extract_ascii.cjs
```
